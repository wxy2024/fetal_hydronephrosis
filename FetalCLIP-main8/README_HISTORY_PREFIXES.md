# 固定患者子集：历史截断评估

## 运行步骤
同步scripts/evaluate_history_prefixes.py到服务器main8的scripts文件夹。
脚本顶部已填入服务器新69号结果与数据路径；FetalCLIP配置和权重默认位于main8根目录。
使用原训练环境wxy_fetalclip，在服务器main8目录运行：

    python scripts\evaluate_history_prefixes.py

建议先将顶部SMOKE_TEST改为True：每折最多抽2位患者、统计重复100次，仅检查流程。
成功后改回False，正式运行105例、Bootstrap与置换各10,000次。
不需要重训或改变训练配置；不覆盖原模型和结果。
依赖：原训练环境、numpy、Pillow、matplotlib及fetalclip特征提取模块。

## 评估方案
固定选取原折外预测中双肾检查次数均≥6的患者，保持患者原测试折。
本地新69号结果确认：105例、210个肾单位，其中阳性60、阴性150。
各阶段使用相同105例、同一组已训练模型：前2次、前3次、前4次、前5次、完整历史。
每个阶段每个肾单位输出一次预测，双肾保留为同一患者簇。不会把多个阶段当成独立患者。
完整模型仍是在原≥2次检查队列中训练，105例仅为固定评估子集。

## 启动核验
每折需要fold_N/final_model.pt，其中包含model_state_dict和metadata（使用新增保存功能训练的文件）。
脚本读取权重中的模型配置，不使用当前训练配置里的模型类型或随机种子来重建划分。
核对模型训练/测试名单、折外预测、原始标签、检查历史、图像顺序；先复现完整历史概率及注意力（容差1e-4），再计算前缀。
若缺权重或复现不一致会停止。不要跳过检查或随意调大容差。
本地当前仅见JSON与CSV，没有.pt；实际模型加载需服务器验证。

## 输出位置和文件
output6_rebuttal/history_prefix_evaluation/FORMAL_时间戳（冒烟测试为SMOKE_）：
- cohort.csv：固定患者、侧别、标签、检查数与折号。
- full_replay.csv：完整历史预测复现误差。
- prefix_predictions.csv：所有阶段的逐肾概率、分类和实际输入检查ID。
- stage_metrics.csv：同一子集各阶段9项指标及95%区间（汇总折外预测计算）。
- fold_metrics.csv：各折各阶段指标，仅供描述。
- paired_comparisons.csv：配对差值、95%区间、未校正P和Holm校正P。
- history_performance.png：AUC、敏感度、F1曲线；full为每位患者自己的完整历史，长度不固定。
- manifest.json：配置、文件哈希及完成状态。只有status=complete才表示完整完成；失败留下的CSV为部分结果。

## 统计含义
9项指标：Accuracy、Sensitivity、Specificity、Precision_PPV、NPV、F1、AUC、BrierScore、ECE。分类阈值固定0.5，ECE使用10个等宽概率区间。
Bootstrap在每个原测试折内部按患者有放回抽样，同次抽样用于所有阶段，保留患者双肾；95%区间为百分位区间。
双侧置换检验以患者为单位交换两个阶段的预测（双肾一起交换），P=(超过或等于观测绝对差的次数+1)/(有效次数+1)。
比较共7组：完整历史分别减前2/3/4/5次，以及前3减前2、前4减前3、前5减前4。对7×9=63个检验统一Holm校正。
差值均为stage_b−stage_a；BrierScore和ECE越低越好，其余指标越高越好。不要仅按差值正负宣称全部指标改善。
AUC在抽样只有单类时不可计算，输出有效重抽样次数。指标沿用原项目零分母记0的约定。
这些区间和检验条件于已训练模型，不包含重新训练的不确定性；试跑结果不得写入论文。

## 可支持的结论
这是完整历史训练模型在较短历史输入下的敏感性分析，反映随访较充分子集的信息可用性变化。
不能证明提前多少天预测，不能直接推广到检查较少患者，也不是训练了专门的早期预测模型。
